# Proof reference bundle

Use this knowledge to deliver one specified story and assess its acceptance evidence. The bundle uses this repository's OKF v0.1 layout; the runtime proof protocol is a separately versioned local convention.

- [Acceptance contract](./acceptance-contract.md): turn intent into observable, frozen obligations.
- [EARS](./ears.md): choose requirement patterns without confusing syntax with test coverage.
- [Verification](./verification.md): independent checks, evidence, and graded results.
- [Lifecycle](./lifecycle.md): responsibilities, repair, revisions, and historical records.
- [Project policy](./project-policy.md): share Definition of Done obligations across stories.
- [Knowledge placement](./okf-profile.md): discover the requirements home and integrate OKF without imposing directory names.
- [Gate protocol](./gate.md): executable schema, CLI, integrity checks, and limits.
- [Worked example](./worked-example.md): trace a story through contract and checks.
- [Sources and decisions](./sources.md): source inventory, corrections, and design authority.
