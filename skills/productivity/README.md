# Productivity Skills

Process and discipline. Not specific to a codebase.

- **[ask-ux](./ask-ux/SKILL.md)**. Force UX questioning before any UI work. UI-vs-UX diagnostic, then twelve questions in the order they bite.
- **[to-story](./to-story/SKILL.md)**. Reshape a Jira or GitHub draft ticket as a real user story with INVEST-clean ACs. Splits oversized stories with SPIDR.
- **[autopilot](./autopilot/SKILL.md)**. Work the project on your own without waiting for direction. Survey, find one high-value low-risk improvement, verify it, commit it, loop. Generate-then-rank judgment for picking the work (a sensible small feature competes on equal footing, not a fixed checklist), in-bounds vs surface-first rails, and anti-churn checks so the human reviews a clean stream of small wins instead of one giant diff.
