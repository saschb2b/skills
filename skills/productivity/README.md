# Productivity Skills

Process and discipline. Not specific to a codebase.

- **[ask-ux](./ask-ux/SKILL.md)**. Force UX questioning before any UI work. UI-vs-UX diagnostic, then twelve questions in the order they bite.
- **[to-story](./to-story/SKILL.md)**. Reshape a Jira or GitHub draft ticket as a real user story with INVEST-clean ACs. Splits oversized stories with SPIDR.
- **[no-slop](./no-slop/SKILL.md)**. Write and revise human-facing prose in a plain, professional register, stripping the tells that mark text as AI-generated. Builds sentences with ASD-STE100 Simplified Technical English, strict for procedures and error messages, relaxed for prose. Twelve construction rules to write by, twenty tells to check against, before/after rewrites, a `slop-lint.mjs` linter scoring violations per 100 words, and a guard against over-correcting into robotic prose. Carries the Microsoft Writing Style Guide mechanics with a house-style mode, and rules for accessible and inclusive wording. Catches list-itis and forced enumeration too.
- **[breadcrumbs](./breadcrumbs/SKILL.md)**. Heal understanding gaps exposed during ordinary implementation, debugging, and investigation. Diagnose misleading information scent, hostile navigation topology, hidden contracts, invisible rationale, fragmented ownership, stale guidance, opaque errors, and accidental complexity, then make the smallest durable repair at the source. Includes a research-backed OKF smell catalog, concrete repair patterns, worked examples, and autonomy rails. The clearer codebase is the breadcrumb; there is no separate trail or knowledge system.
- **[autopilot](./autopilot/SKILL.md)**. Work the project on your own without waiting for direction. Survey, find one high-value low-risk improvement, verify it, commit it, loop. Generate-then-rank judgment for picking the work (a sensible small feature competes on equal footing, not a fixed checklist), in-bounds vs surface-first rails, and anti-churn checks so the human reviews a clean stream of small wins instead of one giant diff.
- **[fable-mode](./fable-mode/SKILL.md)**. Adopt the structural operating discipline of Anthropic's Fable model in whatever harness is running. The operating loop with its altitude decision, parallel dispatch, delegation economy, orchestration patterns, verification gates, faithful reporting (three honest verdicts), the irreversibility gate, context economy, tool and code conduct, memory discipline, and trust boundaries against prompt injection, shipped as a vendored OKF bundle with a harness-mapping runbook and a delta map against the leaked GPT 5.6 system prompt. Governs how work is executed; `autopilot` governs choosing it.
- **[game-design](./game-design/SKILL.md)**. Analyze, design, critique, and rework video game mechanics, systems, and interface. The dissection lens (iconic mechanic, core dialectic, macro loop, design tensions, ludonarrative resonance, patterns, lessons), a cross-game pattern catalog of two dozen patterns distilled from 16 dissected games, the transferable design moves with their caveats, the durable frameworks (MDA, core loops, the flow corridor, motivation, depth vs complexity, game feel), economy and balance theory, a critique smell catalog, an inventory and itemization treatment (storage models, the inventory puzzle, loot, consumables, weight, loadouts), and an interface and UX layer (menus and screens, transitions, onboarding and teaching, dialogue UI, guidance and feedback, input prompts, accessibility), shipped as a vendored OKF bundle. Commands to dissect, pitch, spec a mechanic, design a loop, rework a system, find patterns, compare, design the interface, and teach. Pairs with the engineering `godot` skill: this is the design thinking, that is the engine code.
