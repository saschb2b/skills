# Productivity Skills

Process and discipline. Not specific to a codebase.

- **[ask-ux](./ask-ux/SKILL.md)**. Force UX questioning before any UI work. UI-vs-UX diagnostic, then twelve questions in the order they bite.
- **[to-story](./to-story/SKILL.md)**. Reshape a Jira or GitHub draft ticket as a real user story with INVEST-clean ACs. Splits oversized stories with SPIDR.
- **[no-slop](./no-slop/SKILL.md)**. Write and revise human-facing prose in a plain, professional register, stripping the tells that mark text as AI-generated. Five rules (punctuation, structure, vocabulary, stance, formatting), a tells table, before/after rewrites, and a guard against over-correcting into robotic prose. Catches list-itis and forced enumeration too.
- **[autopilot](./autopilot/SKILL.md)**. Work the project on your own without waiting for direction. Survey, find one high-value low-risk improvement, verify it, commit it, loop. Generate-then-rank judgment for picking the work (a sensible small feature competes on equal footing, not a fixed checklist), in-bounds vs surface-first rails, and anti-churn checks so the human reviews a clean stream of small wins instead of one giant diff.
- **[game-design](./game-design/SKILL.md)**. Analyze, design, critique, and rework video game mechanics and systems. The dissection lens (iconic mechanic, core dialectic, macro loop, design tensions, ludonarrative resonance, patterns, lessons), a cross-game pattern catalog of two dozen patterns distilled from 15 dissected games, the transferable design moves with their caveats, the durable frameworks (MDA, core loops, the flow corridor, motivation, depth vs complexity, game feel), economy and balance theory, and a critique smell catalog, shipped as a vendored OKF bundle. Commands to dissect, pitch, spec a mechanic, design a loop, rework a system, find patterns, and compare. Pairs with the engineering `godot` skill: this is the design thinking, that is the engine code.
